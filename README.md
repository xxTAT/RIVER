# RIVER: Reproducibility Resources

## Associated manuscript

**RIVER: duplex-morphology-guided inference of RNA secondary structures and their alternatives from RNA–RNA interaction maps**

**Authors:** Yingxiang Deng, Zhaoxiang Liu, Lei Chen, Dengguo Wei, and Zi Wen

## Repository contents

This repository provides the materials required to reproduce the analyses, figures, and structural models presented in the manuscript.

### 1. Figure reproduction

The `main_figure/` and `supplementary_figure/` directories contain the source data, analysis scripts, and executable code used to reproduce the main and supplementary figures in the manuscript.

### 2. Structural model reconstruction

The `RIVER_example/` directory contains the input data, scripts, and executable code required to reconstruct structural models described or displayed in the manuscript.

## RIVER software

The integrated implementation of **RIVER (RNA Interaction-guided Variable structure ExploreR)** is maintained in a separate repository: https://github.com/xxTAT/river_rna.

## RIVER Atlas

All structural models generated and analyzed in the manuscript, together with their associated structural attributes, are available through the **RIVER Atlas**: https://github.com/xxTAT/river-atlas.

The RIVER Atlas provides online visualization and downloadable files for the representative structures, well-folded structures, and alternative structures reported in this study.
